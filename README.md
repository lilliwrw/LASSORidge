# LASSORidge

**LASSORidge** is an R package for variable selection and regularized regression in linear models.

The package implements several classical model selection and regularization methods, including:

- Forward selection
- Backward selection
- Least Angle Regression (LAR)
- LASSO
- Ridge regression

It also provides tools for tuning parameter selection via cross-validation as well as utilities for summarizing and visualizing model results.
